# Mod Development

Like Ship of Harkinian, asset modding on 2 Ship 2 Harkinian is driven through o2r files, which override assets extracted from your ROM. Code mods are not supported, as code is not stored in the o2r.

Much of the SoH modding workflow carries over directly, so the [Ship of Harkinian mod development guides](../../ship-of-harkinian/mod-development/) are a good starting point. The pages here cover the tooling and reference material specific to 2Ship.
